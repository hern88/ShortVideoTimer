# 短视频时长（MVP v0.1）

一个安卓 App：**告诉你今天一共刷了多久短视频。**

---

## 一、这个版本做了什么 / 故意没做什么

MVP 的意思是「最小可行产品」——**只做验证核心想法必需的那点功能，其他先全部砍掉。**

| ✅ 这个版本有 | ❌ 这个版本故意没有 |
|---|---|
| 显示今天短视频总时长 | 登录 / 注册 |
| 显示各 App 分别用了多久 | 联网 / 云同步 |
| 一键跳转授权设置页 | 排行榜 / 好友对比 |
| 自动刷新（从设置页返回时） | 图表 / 历史记录 |
| | 定时提醒 / 强制锁机 |
| | 数据库、账号体系 |

**为什么？** 因为要验证的问题只有一个：

> 中学生看到「今天刷了 1 小时 23 分钟」这个数字时，会不会心里咯噔一下？

如果会 → 说明痛点真实，再往下加功能。
如果不会 → 排行榜做得再漂亮也没用，趁早换方向。

## 二、目录结构（每个文件是干嘛的）

```
ShortVideoTimer/
├── .github/workflows/build.yml        ← 云端自动编译的配置（很重要，见第三节）
├── build.gradle                       ← 项目级构建配置
├── settings.gradle                    ← 告诉 Gradle 有哪些模块
├── gradle.properties                  ← 构建参数
│
└── app/                               ← 主模块（App 本体）
    ├── build.gradle                   ← App 级配置：包名、支持的安卓版本、依赖库
    └── src/main/
        ├── AndroidManifest.xml        ← 清单文件：声明权限、注册界面
        │
        ├── java/com/example/shortvideotimer/
        │   ├── UsageAccess.java       ← ① 权限：检查 / 跳转设置页
        │   ├── ShortVideoUsage.java   ← ② 算法：算今天的时长（核心）
        │   └── MainActivity.java      ← ③ 界面：把数字显示出来
        │
        └── res/
            ├── layout/activity_main.xml   ← 界面的排版
            ├── values/strings.xml         ← 所有文字（改文字来这里）
            ├── values/colors.xml          ← 所有颜色（换配色来这里）
            ├── values/themes.xml          ← 主题
            ├── drawable/                  ← 图标、背景形状
            └── mipmap-anydpi-v26/         ← App 启动图标
```

**你就记住三个 Java 文件的分工：权限 → 算数 → 显示。** 一个文件干一件事，改起来不会乱。

## 三、怎么把它装到手机上（不用装 Android Studio）

思路是：**你只管写代码，把代码传到 GitHub，GitHub 的服务器帮你编译成 APK，然后用手机下载安装。**

### 第 0 步：先确认你电脑上有 Git

打开 VS Code，点左边竖排图标里的「源代码管理」（长得像树杈的那个）。
如果提示要安装 Git，就去 https://git-scm.com/download/win 下载安装（约 60MB，一路点下一步）。

### 第 1 步：注册 GitHub 账号

打开 https://github.com → 右上角 `Sign up` → 按提示填邮箱、密码、用户名。
**用户名和邮箱记下来，后面要用。**

### 第 2 步：在 GitHub 上建一个空仓库

1. 登录后点右上角 `+` → `New repository`
2. `Repository name` 填 `ShortVideoTimer`
3. 选 `Public`（公开，Actions 免费且额度无限）
4. **下面的 `Add a README file` 等三个勾全部不要勾**（保持空仓库）
5. 点 `Create repository`

### 第 3 步：在 VS Code 里打开项目并推送代码

1. VS Code 菜单：`文件` → `打开文件夹` → 选中桌面上的 **`ShortVideoTimer`** 文件夹
   > ⚠️ 要打开 `ShortVideoTimer` 这一层，**不要**打开它外面的竞赛文件夹
2. 点左边「源代码管理」图标
3. 点 `初始化仓库`（Initialize Repository）
4. 在上方输入框里写 `first commit`，按 `Ctrl+Enter` 提交
5. 点 `发布分支`（Publish Branch）→ 选择 `Publish to GitHub public repository`
6. 如果弹出登录，选 `通过浏览器登录 GitHub`，浏览器里点一下授权就行

推送成功后，刷新 GitHub 网页，应该能看到你的代码了。

### 第 4 步：等云端编译（大约 3~5 分钟）

1. 在 GitHub 仓库页面点顶部的 **`Actions`** 标签
2. 会看到一条叫「编译 APK」的记录，黄点 = 正在编译，绿勾 = 成功，红叉 = 失败
3. 第一次编译会慢一些（要下载 Gradle 和依赖库），耐心等

> 💡 编译成功后，页面最上方的**摘要区会直接显示你该用手机打开的下载链接**，不用自己拼。
>
> 💡 如果显示红叉，点进去看哪一步标红了，把报错发给我。

### 第 5 步：手机下载安装

**方法 A（推荐，不用登录 GitHub）：**

手机浏览器打开这个地址（把 `你的用户名` 换成你的 GitHub 用户名）：

```
https://github.com/你的用户名/ShortVideoTimer/releases/download/latest-apk/app-debug.apk
```

**方法 B（备用）：**

在 `Actions` 页面点进那次成功的构建，最下方 `Artifacts` 里下载 `ShortVideoTimer-APK`（是个 zip，需要解压，而且要登录 GitHub）。

**安装时：**
- 手机会提示「不允许安装未知来源应用」→ 点「去设置」→ 允许你的浏览器 / 文件管理器安装应用 → 返回重试
- 部分手机会有「安全检测」弹窗，选「继续安装」/「无视风险安装」

### 第 6 步：打开 App 并授权

1. 打开 App「短视频时长」
2. 点 **「去开启使用情况权限」**
3. 在系统设置列表里找到 **「短视频时长」**，把右边的开关**打开**
4. 按返回键回到 App → 数字会自动出现

> 找不到开关？不同手机路径不一样：
> - 小米 / 红米：设置 → 应用设置 → 应用权限管理 → 特殊权限 → 使用情况访问
> - 华为 / 荣耀：设置 → 应用 → 特殊访问权限 → 使用情况访问
> - OPPO / 一加：设置 → 应用管理 → 特殊应用权限 → 使用情况访问
> - vivo：设置 → 更多设置 → 权限管理 → 特殊权限 → 使用情况访问

## 四、改代码的速查表

| 我想…… | 改哪个文件 |
|---|---|
| 改 App 名字 | `res/values/strings.xml` 里的 `app_name` |
| 换主题色 | `res/values/colors.xml` 里的 `brand` 和 `brand_dark` |
| 增加统计某个新 App | `ShortVideoUsage.java` 的 `APPS` 里加一行 `APPS.put("包名", "中文名")` |
| 不统计某个 App | 把 `APPS` 里对应那行删掉 |
| 改界面排版 | `res/layout/activity_main.xml` |
| 改授权引导的文案 | `res/values/strings.xml` 里的 `hint_need_permission` |

改完代码后：源代码管理 → 写提交信息 → `Ctrl+Enter` → `同步更改`，等 3~5 分钟就能在手机上装新版了。

## 六、常见问题

**Q：显示 `--`，一直不出数字？**
没授权。点按钮去设置里把开关打开。

**Q：数字一直是 0 分钟？**
① 先确认今天确实刷过；② 确认权限开关是打开的；③ 有些手机首次授权后需要等几分钟，系统才开始记录数据。

**Q：为什么和手机自带「数字健康」里的数字对不上？**
两种可能：一是只要 App 在前台就计时，分屏（同时两个 App 在前台）会重复计算；二是息屏瞬间正在前台的那一段可能没算完。这个精度对 MVP 够用了。

**Q：能统计别人手机上的数据吗？**
不能。安卓的隐私设计就是如此，只能统计本机，且必须机主本人授权。

**Q：GitHub 打不开 / 太慢了？**
多刷新几次，或者换个网络（用手机热点试试）。实在不行只能装 Android Studio 在本地编译（约 10GB，我不推荐）。

**Q：想改包名 `com.example.shortvideotimer`？**
改 `app/build.gradle` 里的 `namespace` 和 `applicationId`，同时把 `java/com/example/shortvideotimer/` 文件夹和三个 Java 文件顶部的 `package` 语句一起改掉。**文件路径和 package 名字必须一致。**

**Q：`colors.xml` 或者 `README.md` 又不见了怎么办？**
`colors.xml` 不能删 —— 主题和界面都在引用里面的颜色，删了会直接编译失败。如果发现文件丢失，把情况告诉 Copilot，让它按引用关系重建即可。

## 七、合规提醒（参赛 / 上架都要注意）

- 这个 App 用到了**特殊权限** `PACKAGE_USAGE_STATS`，属于高度敏感的隐私权限。
- **必须**在介绍 / 说明中明确告诉用户：需要这个权限是为了统计使用时长，不做其他用途。
- 数据**只存在手机本地**，不联网、不上传（当前版本就是这样）。
- 如果要上架应用商店，需要在隐私政策里单独说明这条权限。Google Play 对「使用情况访问」和「读取应用列表」有专门的审核要求，写清楚用途一般能过，用来做广告推送会被直接下架。
- 本项目定位应明确写为「**数字健康 / 自我管理工具**」，这是唯一能站得住脚的用途。
